# Finding template

Group findings by domain: colour/contrast, typography, layout/spacing, components/states, accessibility, motion, Windows-native fit, content.

```
### <short title>
- Domain:
- Stage (perception-model): arrival / first look / orientation / doing / living with it
- Evidence: observed | inferred | needs-your-eye   (+ how it was seen: method #, state, DPI, theme)
- What the user sees or feels:
- Why it matters (lens: heuristic / WCAG / Fluent / motion):
- Severity: S0-S3
- Suggested direction (one line, no code):
- Not verified:
```

## Rules
- Lead with the answer; one finding per block.
- Say what still needs the user's eyes.
- Never present a still image as proof of motion, latency or backdrop effect.
