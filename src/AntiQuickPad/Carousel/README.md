CarouselController composes CarouselMotion (behaviour) and CarouselView (presentation), retaining the existing caller surface. CarouselMotion owns the 140 ms wheel burst gate, drag origin/samples/velocity, half-page or velocity snap, selection callback, 280 ms slide, easing, cancellation versions and frame samples. It accepts numbers and an ICarouselSurface bridge; it contains no Avalonia controls or wall clock. RunSmoke includes a control-free surface driving exact frame timestamps.

CarouselView owns the viewport, transforms, current/preview decoration, page stride, read-only neighbour editor, grab strip, brushes, fonts, cursor and tooltip. It forwards wheel and pointer input to motion, maintains pointer capture, and supplies TopLevel frame timestamps. Motion supplies both transform offsets and requests preview/reset/read-only changes through ICarouselSurface. The current and requested notes alone are laid out. Ordinary vertical wheel scrolling remains with the editor. MainViewModel owns note selection; Core owns persistence; the resident controller retains per-note runtime scroll positions.

To restyle, change Look inputs or CarouselView and the caller-supplied page decorator/stride. Leave CarouselMotion gesture/timing/selection policy alone. Physical mouse wheel feel, pointer capture outside the grab strip, release and cancellation still need the user's desktop check.
