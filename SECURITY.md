# Security

AntiNotepad is a local desktop app. It stores notes on your machine and makes no network connections of its own.

- **Report a vulnerability privately:** use GitHub's "Report a vulnerability" button on the Security tab of this repository.
  - *Please don't open a public issue for a security problem.*
- **What helps:** the version, your Windows version, and steps to reproduce.
- **What to expect:** this is a personal project, so replies can take a few days.
- **Supported versions:** only the latest release.
