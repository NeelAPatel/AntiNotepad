# Getting started

Download the portable release and make a first note.

- Starting with the first release, download the unsigned zip from [Releases](https://github.com/NeelAPatel/AntiNotepad/releases), extract it, and run `AntiNotepad.exe` on Windows 11. Windows may show a warning because the build is unsigned; check the release notes for runtime requirements.
- Press **Ctrl+Alt+Shift+S** to show or hide the pad. The tray icon also provides access to the app.
- Type a note. Press **Ctrl+N** for another, and **Alt+Left** or **Alt+Right** to move between notes.
- Notes are local; the default folder is `Documents/AntiNotepad`. Choose another location in Settings. See [[Architecture and Data]] for saving and recovery limits.
- Press **F1** for the in-app shortcut list. See [[Settings and Shortcuts]] to change keys and appearance.
