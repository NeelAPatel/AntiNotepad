# Building with AI and lessons

I use this project to learn about AI models, agents and orchestration while building a useful app.

- AI leads much of the implementation and investigation. I set direction, approve plans, examine reports and test visible behavior myself.
- PStack and agent configurations help organize the work; cards and reports preserve decisions and evidence. The [building-with-AI index](https://github.com/NeelAPatel/AntiNotepad/blob/main/docs/building-with-ai.md) links to the configurations and records.
- The loop has changed over time:
  - *October 17–29, 2026: early product and process work, followed by a history rewrite and process redesign.*
  - *October 30–November 5: loop v3 made worktrees, gates and audits more explicit.*
  - *November 6–22: loop v5 and later refinements changed merge policy, guards and the one-chat item flow.*
- I have seen a paste change need rework for deep nesting and performance, a shortcut audit miss window-level bindings, and a self-test hang. My hand tests have also caught unwanted behavior.
  - *I use real-shaped inputs for hook tests, check window handlers for shortcut conflicts, and stress parsing. A green check is evidence, not a guarantee.*
