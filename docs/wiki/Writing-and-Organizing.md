# Writing and organizing

Use the stack, slots and note modes to keep quick work close.

- The stack holds ordinary notes; slots 1–9 hold permanent slot notes. Split view shows a slot beside the current note; **Ctrl+\** toggles it by default.
- Put a mode keyword on the first line of a note:
  - *`checklist`, then `[ ] milk`, starts a checklist; `bullet` and `numberlist` choose other list styles.*
  - *`timer`, then `25m focus`, creates a countdown; Enter starts it.*
  - *`math`, then `rent = 1200` and `rent / 3`, uses the inline calculator. It also handles units and dates.*
- Press **Ctrl+F** to search notes. Search offers list and grid views and a Trash view for deleted notes.
- Use the screen-snip text reader with **Ctrl+Shift+O** by default. See [[Settings and Shortcuts]] for configurable bindings.
