# Settings and shortcuts

Adjust the pad, storage and keys to fit the way you work.

- Open Settings with **Ctrl+,**. Appearance settings include paper, palette and text size; Storage lets you choose the notes folder.
- Change the global show/hide hotkey in Settings. A separate global new-note hotkey can be configured; it is off by default.
- Configure in-window shortcuts in Settings. Some bindings are initially unassigned, and fixed editing and system keys have restrictions.
- Press **F1** in the pad for the active shortcut list. The [shortcut reference](https://github.com/NeelAPatel/AntiNotepad/blob/main/docs/shortcuts.md) lists defaults and fixed keys.
- Choose a save delay in Settings. The default is 0.4 seconds; longer choices are available. See [[Architecture and Data]] for the limits of saving.
