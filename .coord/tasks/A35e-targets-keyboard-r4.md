1. **Float bar layout (BarStyle.Float only; docked and overlay unchanged).** One pill: [Delete/Clear] | pager | [New]. "Present" = visible (a disabled but visible Delete or New still counts). Gaps: 8 px (`Space.S`) each side of every separator, 4 px between buttons inside the pager, 1 px separator; remove the separators from inside the pager row and from the old `DeleteSeparatorMargin` special case (delete the token if unused). Slots view: [Clear] | nine 24 px dot targets, no New. Standard view: [Delete] | < 2 / 2 > | [New]; New hidden by its setting means no trailing separator.
2. **Shadow.** The float bar sits in its own transparent popup (`_floatPager`) whose size equals the pill, so the pill's soft shadow (`PillShadowBlur` 12, offset 2) is clipped at the window edge. Pad the popup content by the shadow's reach (blur plus offset, token `PillShadowReach`) on every side and subtract the same amount from the popup placement offsets so the pill stays where it is; the pad area must not take pointer input or block the pad underneath. The pill still fades with the existing bar fade.
