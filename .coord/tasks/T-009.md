## F19 active indent guide
Like VS Code: the guide for the innermost indented block containing the caret is drawn brighter (Look.IndentGuideActive, about 2x the contrast of Look.IndentGuide; same 1 DIP or 1.5 DIP). Only that one guide, over that block's vertical extent. Redraw on caret move (invalidate the layer only, no relayout). Caret on an unindented line: no active guide. Inside code fences use the fence body's indentation.
Proof: render `.coord/reports/T-009-active.png` with caret inside a nested list item and inside a python body; measure the active column is brighter and the others unchanged. View the PNG yourself.

## F18 graceful --quit
`AntiQuickPad.exe --quit`: if a resident copy runs, signal it over the existing single-instance channel to save and exit (same path as tray Quit, logged quit-start/quit-finish with source=command), wait up to 5 s for it to exit, exit 0; exit 0 immediately if none runs; exit 1 with a message if it did not exit in time. Must not start a second resident or show the window.
Selftest: isolated-name resident receives quit signal and exits cleanly.
