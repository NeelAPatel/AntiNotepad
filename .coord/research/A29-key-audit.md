# A29-shortcut-map-keyaudit

**The key finding:** the window handles shortcuts in the tunnel phase, before the editor. Consequently, today’s **Alt+Shift+Up/Down move a note and shadow AvaloniaEdit’s rectangular selection**. Alt+Shift+Left/Right also navigate notes because the window’s Left/Right cases do not exclude Shift. The inventory’s claim that those two combinations fall through is incorrect.

This is a static, offline audit; AntiNotepad was not launched. The project uses Avalonia **12.1.4** and a checked-in AvaloniaEdit **12.0.0** source copy, rather than the cached AvaloniaEdit package directly: [project](/F:/LocalVSProj/Visual%20Studio%20Apps/AntiQuickPad/.claude/worktrees/feat/A29-shortcut-map/product/AntiNotepad/AntiNotepad.csproj:48), [upstream provenance](/F:/LocalVSProj/Visual%20Studio%20Apps/AntiQuickPad/.claude/worktrees/feat/A29-shortcut-map/third_party/AvaloniaEdit/UPSTREAM.txt). I found no AvaloniaEdit XML docs in the cache. Avalonia’s cached XML describes its platform keymap API but does not enumerate the Windows TextBox bindings, so the TextBox-specific list below is **not complete or package-verified**.

## 4. Safe space

**No combination can be certified universally safe from this offline audit.** The candidates below mean “no explicit collision found in the requested app handlers or inspected editor command declarations,” subject to TextBox, keyboard layout, accessibility software, global hotkeys and a complete binding audit. Check exact modifiers: the existing window handler sometimes consumes supersets.

| Modifier group | Candidate space and known occupation |

| Ctrl+letter | Candidates include **E, J, L, M, Q, R**; verify TextBox and conventions first. A/C/D/I/V/X/Y/Z are editor operations; F/N/P/K/T are app commands; H is an editor replace declaration whose active installation is unverified. B/O/S/U/W have conventional meanings. |
| Ctrl+Shift+letter | Candidates include **E, J, L, M, R** pending control and convention checks. C/O/Q are app commands; Z should be reserved for redo convention; other letters need evaluation rather than blanket approval. |

| Ctrl+Alt / Ctrl+Alt+Shift | Avoid printable-key combinations on layouts using AltGr, **from memory, not verified**; also compare global registrations and reserved dev slots. |
| Function keys | F1 is help, F11 is dev probe, F12 can capture; other F-keys require OS, browser and control checks. F1–F9 with Ctrl+Alt+Shift are proposed reserved dev slots. |

## 5. Recorder rules

[HotkeyRecorder.cs:55](/F:/LocalVSProj/Visual%20Studio%20Apps/AntiQuickPad/.claude/worktrees/feat/A29-shortcut-map/product/AntiNotepad/UI/HotkeyRecorder.cs:55) accepts A–Z, top-row 0–9, F1–F24, Space, Escape, Tab, Enter, Insert and Delete **only with at least one Ctrl, Alt or Shift**. It rejects Meta, unsupported main keys and modifier-only gestures; it stores modifiers in Ctrl, Alt, Shift order. Unmodified Escape cancels and unmodified Enter applies a pending gesture through `IsCommand`; while recording, keydown is marked handled: [HotkeyRecorder.cs:175](/F:/LocalVSProj/Visual%20Studio%20Apps/AntiQuickPad/.claude/worktrees/feat/A29-shortcut-map/product/AntiNotepad/UI/HotkeyRecorder.cs:175).

For an in-window recorder, additionally:

1. Refuse the text-editing, OS and fixed-app reservations above, including modifier variants and contextual bindings.
2. Reject collisions with all current **and configured** global hotkeys and dev slots; check canonical equivalents and numpad/OEM representations.
3. Detect conflicts across window, editor, search and completion scopes, including predicates that accept extra modifiers; do not assume different display strings mean different events.
4. Treat AltGr and layout-dependent punctuation conservatively; validate the gesture on the active layout and avoid stealing text input.
5. Define whether a shortcut is global to the window or scoped; refuse a binding when its route would preempt editing or an overlay, even if another scope currently uses the same key.
6. Provide a clear reason for refusal and preserve Escape/Enter as recorder controls. Extend supported keys deliberately if arrows or punctuation are offered.
