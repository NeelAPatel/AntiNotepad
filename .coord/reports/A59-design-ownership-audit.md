# A59-design-ownership-audit

## 1. Summary

The P1-project-reevaluation-plan section 2 survey is substantially confirmed: 57 C# files / 16,664 physical lines, five individual files above 600 lines, scattered design decisions, parallel control composition and repeated path rules. Corrections: menu/dropdown shadow blurs differ (18/16), and Settings contains a third same-or-nested path implementation; rendering already shares resource factories, while its caches deliberately have different bounds and keys; Settings controls already use `Kit.Plain`, so this is partial duplication rather than two independent kits. Missing from the survey are literal drawing geometry, heading size multipliers/rainbow colors, Settings preview values, settings defaults and platform timing/invisible-window dimensions; these belong in the scan baseline even where they should remain local behavior constants. Preserve every current value and formula during migrations; section 7 of P1-project-reevaluation-plan already settles lab-first visible changes, spacing count non-growth, no Calculator/PadWindow splits, exact file scopes and two release markers, so those decisions are not reopened here.

## 5. Design value catalog

Counts are semantic occurrence keys `(category, file, line, value)`, not numeric-character counts; tuples/formulas and same-line identical values are grouped. The distinct count is the number of exact `value` expressions (units/wording retained); large categories list their distinct scalar atoms below, with complete distinct tuples/formulas recoverable from the TSV.
