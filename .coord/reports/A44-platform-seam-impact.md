# A44-platform-seam-impact

Read-only source audit, 2026-10-25. Product baseline/worktree HEAD: `b54b476`, branch `reorg/A44-platform-seam`. Paths below are relative to `product/AntiNotepad` unless prefixed with `docs/` or a sibling label. No build, selftest, launch, shutdown, or visual verification performed. Only this report was written; the explicit report-only restriction overrides the normal STATUS update rule (`AGENTS.md:18`).

Recommendation: one thin static `DesktopPlatform` for the existing Native operations; retain the existing stateful Platform services. Preserve every call site, dispatch priority, handle owner and disposal sequence. No frame-style change (`docs/decisions.md:18-23`; `UI/PadWindow.cs:49-52`). A38's rationale is recorded at `feat/A38-mvvm-audit:docs/A38-mvvm-audit.md`, especially its targeted-modularity recommendation.

## (b) Proposed facade shape

**Proposal, not implementation:** add `internal static partial class AntiNotepad.Platform.DesktopPlatform`. Nine forwarding members preserve the current Native signatures and bodies; no injected dependency/container, per-call allocation, extra await, event, dispatcher post or handle cache. Retain existing services rather than duplicating every service as a static forwarding method (existing surfaces listed above).

```csharp
// DesktopPlatform: cursor, clipboard, sound, memory, popup styling, shell.
internal static PixelPoint CursorPosition();
internal static IDisposable ListenClipboard(Window window, Action changed);
internal static bool ClipboardIsPrivate();
internal static void Chime();
internal static void TrimWorkingSet();
internal static void ConfigurePopupWindow(TopLevel popup);
internal static void Flash(Window window); // Preserve existing unused capability; no new caller.
internal static void OpenUrl(string url);
internal static void StartScreenSnip();

// Also move the existing Windows shell/diagnostic bodies if taking the complete OS seam:
internal static void OpenFolder(string path); // explorer.exe + ArgumentList.Add(path), no catch here
internal static (long PrivateBytes, long WorkingSetBytes, int ThreadCount)
    ReadCurrentProcessMetrics(); // using Process.GetCurrentProcess; same sample order
```
