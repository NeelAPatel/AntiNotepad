# T-004 — M0, M1, M2 complete

2026-10-17. Director integrated two bounded Luna workers (Notes and Shell services). Only src/AntiQuickPad/ and the two authorized T-004 report/status files were written. No git operations, network, spike edits, or shared STATUS.md edits. Manager owns commits.

## Built

- M0: Program/App/MainWindow separation; Shell, Notes, Editor, Carousel folders; one default Look record for palette, interface/editor fonts, size and gutter; RuntimePaths. Opaque themed window, AvaloniaEdit styling. The integrated GUI selftest opened and focused this window.
- M1: One borderless, topmost resident window/editor; hide/show retains both. Esc hides; tray Show / Hide and Quit; tray click shows/focuses. SID/logon-scoped mutex/event enforces one resident process; second launch signals show, including requests received during startup. Ctrl+Alt+Shift+A registration uses Avalonia's Win32 hook and MOD_NOREPEAT. Default is defined in GlobalHotkey.DefaultGesture; override through ANTIQUICKPAD_HOTKEY (e.g. Ctrl+Alt+F8). Registration outcome/errors are logged and unavailable status appears in the tray tooltip. Reopen briefly accents the window border without delaying focus.
- M2: NotesSession exposes note list, CurrentIndex, Current, CreateNote, DeleteCurrent, Select, UpdateCurrent and Save. MainWindow exposes CreateNote, DeleteCurrentNote and SelectNote; Ctrl+N creates a note. No carousel UI yet. GUID-named plain .md files plus notes.json for order/current index/caret. Same-directory temporary files are renamed over destinations; manifest is written after content. Autosave debounces text/caret changes by 350 ms; hide/quit flush synchronously. Save errors retain the open window and show a status message. Corrupt manifests/missing content fail loading rather than silently replacing notes.

Normal data: %LOCALAPPDATA%/AntiQuickPad/notes/. Log: %LOCALAPPDATA%/AntiQuickPad/logs/shell.log. Selftest uses a unique bin/Release/net10.0/selftest/<id>/ directory, bypasses the production singleton and hotkey/tray, and never touches real notes. Its isolated singleton check uses separate names. Test artifacts are retained in ignored build output for inspection.
