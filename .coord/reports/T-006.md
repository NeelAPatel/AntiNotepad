## Per-item changes

1. **Heading folding:** sections stop before the first pair of consecutive whitespace-only blank lines outside code, or before the next heading of equal/higher rank. Lower-rank headings remain nested. Fence folds remain independent, and blank pairs inside fences do not truncate the section. Selftest checks exact end offsets for blank-pair, equal/higher heading, nested heading, and independent fence cases.
2. **Strike:** replaced the stock thin strike with a font-scaled decoration: Look.StrikeThicknessEm = 0.1, giving 1.7 DIP at the default 17 DIP font. Avalonia font metrics determine strike placement through the x-height. Investigation found the old strike pass explicitly rebuilt every struck run with Normal style/weight after bold/italic had formatted it. Strike now applies decoration alone and preserves the existing typeface, weight, style, and size. Actual glyph appearance and line centering across fonts/DPI still need the user's eyes; the smoke fixture lays out the decorated text but does not assert visual quality.
3. **Enter list continuation:** unmodified Enter with no selection continues -, *, +, and numbered . or ) bullets at the same indentation. Numbered bullets increment, task items reset to [ ], and empty items remove the marker while preserving indentation. Caret-position splits retain trailing text; document newline style is retained. Code lines and read-only previews keep their existing Enter behavior. Each operation uses one document update/replace and undoes in one step. Selftest covers plain/indented/tab-indented bullets, unchecked/checked tasks, numeric increment including 9 to 10, and empty bullet/number/task exits, with undo restoring each input.
4. **Marker dimness:** added the dedicated Look.MarkdownMarker value #7E8B9B, reduced from the former shared Muted #9BA9B8. Heading/inline/fence/language markers use it; general interface muted colors stay separate. Readability and visual contrast need the user's eyes.
5. **Quit logging/recovery:** Quit logs quit-start; window closure logs quit-finish before disposing the logger. Save failures retain the existing full exception log, add quit-aborted with the failure reason, restore/show/focus the window, and keep the save-error status visible. The selftest exclusively locks its isolated notes manifest to exercise the actual SaveNotes/Quit failure path, checks visibility/status/logging, then releases the lock and verifies successful Quit start/finish ordering after shutdown. User notes and any resident instance are untouched.
