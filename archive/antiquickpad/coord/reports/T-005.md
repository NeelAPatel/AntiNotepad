## Built

- **M3:** H1–H6 sizes and per-level colours; bold, italic and strike with dimmed visible source markers; bullet decoration. A cached document scanner feeds decoration, folding, checkbox generation and fenced panels. Python uses a bounded line lexer; language comes from python/py fences, a first-line `python:` note, or `python:` as the first content line of an unlabelled fence. Unknown fence languages still receive a code font and panel. Code panels use `IBackgroundRenderer`.
- Inline checkbox widgets replace the three marker characters, show a hand cursor, and toggle the underlying Markdown through a direct control click handler. The replacement is undoable with Ctrl+Z. Read-only previews cannot toggle. Tab/Shift+Tab indent/outdent a caret line or selected lines. Heading and fence folds retain their opening label. `Look.ShowFolding` and `Look.ShowGutter` control the features (default folding on, numbers off).
- **M4:** Horizontal wheel and Shift+vertical wheel move one adjacent note with a 220 ms cubic ease-out slide. A burst owns one destination: input during the slide and until 140 ms idle is coalesced. There are **zero queued steps**, within the requested at-most-one bound; a burst cannot accumulate multiple pages. Edges stop at the first/last note.
- The thin, permanent top grab strip manipulates the note position 1:1. Release chooses the nearest page at half the viewport width, or advances with a velocity of at least 0.55 px/ms. Short slow drags return; edge dragging is resisted. Pointer-capture loss, deactivation, resize, hide and note commands cancel safely. Text-body selection and ordinary vertical scrolling keep their normal routes.
- A small `n / count` indicator fades after 1.4 seconds idle. Ctrl+N creates; **Ctrl+Shift+Delete** deletes without confirmation and retains at least one note. Shortcut hints are in the indicator tooltip.
- One resident editor and one read-only neighbor preview are retained. Only the current/requested notes are laid out; showing the window does not rebuild or relayout the full note collection. Preview undo history is cleared when rebound. Switching preserves per-note caret and scroll within the session. NotesSession/M2 files and manifest format were not changed; scroll is runtime state, while M2 continues persisting text/order/current index/caret.
- New palette, type, geometry and feature values live in the single default `Look` record. No theme picker or M6b hover/pin/window changes were added.

## Verification

Final Release build: **exit 0, 0 warnings, 0 errors**. Final `--selftest`: **exit 0**.

The requested default-output build reached the apphost-copy step but failed because the existing resident process (observed PID 43644) locks `bin/Release/net10.0/AntiQuickPad.exe`. That process was left running. Verification used a separate Release output directory:

```powershell
# From src/AntiQuickPad
$env:AVALONIA_TELEMETRY_OPTOUT='1'
dotnet build -c Release --no-restore -p:OutputPath=bin/T005Release/ -p:UseSharedCompilation=false
dotnet bin/T005Release/AntiQuickPad.dll --selftest
```

`UseSharedCompilation=false` avoided an approximately 22-second shared-compiler delay observed during intermediate builds. No restore or network access was used. The manager can quit the old resident and rerun the ordinary requested build before committing; the normal resident executable has not been refreshed by this verification.

Final internal show-to-focus samples: **4.453 ms, 1.652 ms, 2.615 ms**, all below 100 ms. M3-only checkpoint samples were 5.877 / 4.524 / 2.286 ms. These are scripted Release focus timings, not physical hotkey-to-paint latency or a performance distribution.

Selftest retains M2 debounce, next-process persistence, isolated singleton signaling and same-editor focus checks. Added checks classify Markdown/Python fixtures, verify checkbox text replacement and undo, caret/selection outdent, and lay out an H1–H6/checkbox/fence fixture in the actual editor. M4 checks exercise the real controller through its input entry points: one notch plus burst/trailing event moves exactly once, direct movement is 1:1, long drag advances, short drag returns, velocity/edge math, caret plus a nonzero 300 px scroll survives switching, cancellation restores editing, and repeated delete keeps one note. Physical device events are not synthesized.

## Avalonia limits and implementation findings

- AvaloniaEdit natural font line height remains; no independent leading. Inline checkbox rows can be slightly taller. Code panels have no per-line inner text padding.
- Stock fold marker geometry/guide styling is limited; the marker brush comes from Look. Opaque rectangular window behavior remains unchanged.
- The integrated probe found `TextEditor.ScrollTo*Offset` did not update the live template here. `EditorViewport` restores the actual template ScrollViewer.Offset instead; the nonzero-scroll round trip now passes.
- Python colouring is a small line lexer, not a full Python parser (for example, multiline strings are approximate). Markdown decoration is deliberately a bounded scanner, not a complete CommonMark implementation.
