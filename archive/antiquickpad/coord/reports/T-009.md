# T-009 — active indent guide (F19) and graceful --quit (F18)

Completed 2026-10-18. PASS. No git, network, shared STATUS.md edits, or process termination. All edits/build/selftest artifacts stay in src/AntiQuickPad/ and the authorized T-009 report/status/PNG paths.

## Implementation

- `Look.IndentGuideActive` is #71859B versus normal #445160; both use the existing 1 DIP thickness. On the editor background #171D25, the active RGB distance from the background is exactly 2x normal. The caret selects the deepest completed four-column indent on its line. Only that column brightens across the contiguous block at that depth, stopping on a dedent, fence delimiter, or code/text transition. Blank continuation uses the existing guide-depth rule. Fence body indentation is read from the body, not the delimiter. Unindented caret lines have no active guide.
- Caret PositionChanged updates the renderer's caret line and calls `InvalidateLayer(KnownLayer.Background)` only; this handler does not request layout or regenerate visual lines.
- `--quit` returns before constructing Avalonia or acquiring residency. It opens the existing per-user/session singleton objects, signals the added Quit event, and uses the resident PID published in a named mapping to wait for actual process exit within a shared 5-second budget. No resident returns 0 immediately. Timeout returns 1 with `AntiQuickPad --quit: resident did not exit within 5 seconds.` Normal second-launch Show signalling is unchanged.
- Resident command quit dispatches to the same save/close/shutdown method as tray Quit. Start and finish logs include `source=command`. If saving fails, the command path logs the failure and keeps the resident alive without showing its window; the client eventually times out. Tray save-failure visibility remains intact.
