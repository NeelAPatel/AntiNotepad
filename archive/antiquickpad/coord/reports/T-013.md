## Delivered

- Both layouts run in the real resident application through `Views/Common/ResidentShellWindow`, implementing IShellView over the existing MainViewModel and ShellServices. Quiet is the fresh/legacy-classic-Ink default; explicit `--shell classic` and unknown shell IDs retain the Classic fallback. More switches Quiet/Card without process/window restart.
- Four palettes: approved Quiet/Card light tokens, sage/charcoal Quiet dark, and blue/slate Card dark. More offers persisted System/Light/Dark. `ThemeService` listens to Avalonia Windows platform color changes and updates the open editor, menu, bars and surfaces. Invalid/legacy LookId maps to System. Existing ShellId/LookId fields persist the preferences through the VM settings adapter.
- Runtime appearance changes transfer the same TextDocument and undo stack, caret and scroll to the new editor visual. EditorFactory.Release unhooks scanner/folding/render subscriptions and detaches the old text area. Ordinary hide/show retains the same editor instance. No data migration.
- Unified in-client toolbar with New, More, Pin, Minimize, Close=hide; Quiet footer navigation/count/save/Esc/delete; Card floating pager plus exact count/save. Bars stay laid out at .65 idle opacity and become fully opaque on pointer hover or keyboard focus. Menu supports Tab cycling, arrows, Home/End, Enter/Space and Escape; clicking the editor or navigating dismisses it.
- Production EditorFactory includes the active row (F20), clickable chevron fold margin (F24), regular base typography, original checkbox/strike/code/indent renderers, narrow scrollbars and empty-note hints.
- Existing carousel wheel gate/direct drag/220 ms completion continues to select through MainViewModel. An optional UI page decorator/stride lets Card slide both complete framed surfaces with a 24 DIP inter-card gap. Quiet slides its page. Card edge peeks follow actual neighbour availability; interactive dots use a maximum-eight sliding window with exact count (including >8 notes).
- Resident save/debounce, navigation capture, per-note scroll, pin/bounds, save-failure/quit handling, global hotkey, tray, singleton signalling and command-only --quit reuse the existing lifecycle/services.

## Intentional differences from approved T-011

- Menu now contains the requested functional Theme and Shell groups, New/Delete and Quit, replacing proposed Settings/folder/shortcuts affordances. It is narrower (250 DIP), taller, and keyboard operable. No inactive menu placeholders.
- Production Quiet retains the existing subtle 15 DIP grab strip (three dots above the writing surface), while compensating insets so main writing geometry matches the approved view. Card uses a transparent top-edge grab region with no visible ellipsis.
- Card dots are buttons with larger invisible hit areas, making the floating pager slightly wider. The selected dot/range follows actual notes; the ninth-note empty state has no right peek because no next note exists. Peek labels say Previous/Next note rather than fixture titles, and use the shell surface palette.
- Carousel images freeze the real controller at -350 DIP, rather than T-011's independent per-page transforms. Card now uses real page width + 24 DIP spacing; incoming sample text is shorter, and the read-only preview's active row is at its own caret. These are actual production visual trees, not hand-posed substitutes.
- The unified client toolbar replaces the design host's external standard caption. Native OS borders/shadow/snap flyouts are outside RenderTargetBitmap. Quiet/Card minimum size is 600x480 DIPs; existing smaller saved bounds are clamped to keep toolbar/footer controls usable.
- Dark palettes are newly designed; T-011 only approved the light Quiet/Card directions. Existing natural font leading and flush-left code-panel text remain.
