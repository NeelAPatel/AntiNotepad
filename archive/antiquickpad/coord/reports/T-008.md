## Implementation

CheckboxRenderer draws on KnownLayer.Selection over transparent three-character task markers. Removing the inline Border/Path means checkbox controls cannot enlarge text rows. The box centre uses the text-line baseline minus half the actual x-glyph height, matching StrikeRenderer's baseline calculation and fallback. The check path is centred by its ink extents, including round caps. Hit testing uses the drawn box rectangle; pointer hover sets the hand cursor and tooltip; left press toggles the underlying marker through the existing undoable document operation. Read-only editors still reject changes. Existing marker text advance remains intact.

IndentGuideRenderer implements IBackgroundRenderer on KnownLayer.Background, after the code panel and below text. It draws at every completed four-space indent level; tabs advance to four-space stops (editor indentation size explicitly set to 4). Guide positions use the relevant editor/code font's measured space advance. Look.ShowIndentGuides, Look.IndentGuide (#445160), and Look.IndentGuideThickness (1 DIP) control appearance. Column zero has no guide. Blank runs carry only the levels shared by the nonblank lines on both sides; trailing blanks and code/list block transitions stop the guides.
