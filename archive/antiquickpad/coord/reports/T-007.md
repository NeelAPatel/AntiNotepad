# T-007 — strike, list indent, standard chrome and app bars

Completed 2026-10-18. All four items implemented and verified with the real Avalonia application selftest. No git commands, network, shared STATUS.md edits, or process termination. Writes stayed in src/AntiQuickPad/, this report, .coord/status-T007.md, and the explicitly requested strike PNG.

## 1. Strike — PASS

Removed TextDecoration entirely from the strike pass. StrikeRenderer implements IBackgroundRenderer on KnownLayer.Selection above text. It clips each struck span to visual elements, gets wrapped segment rectangles from BackgroundGeometryBuilder, and uses each run's foreground/typeface/font size. Thickness is max(1.5, 0.1 * font size) DIP (1.7 DIP at 17 DIP). Placement is baseline minus half the actual x glyph height: Avalonia 12 exposes glyph bounds rather than an XHeight metric. The renderer does not change text run properties.

The selftest renders the exact requested fixture through RenderTargetBitmap at 96 DPI (scale 1):

`plain ~~strike~~ **~~bold strike~~** *~~italic strike~~*`

Artifact: [T-007-strike.png](T-007-strike.png), 798 x 510 pixels. PNG was visually inspected. Measured strike height: **2 pixels**, rows **35 and 36** in the regular strike segment.

Mean normalized glyph ink coverage, excluding the strike rows and background/coverage <= 0.10: plain **0.7869**, strike **0.7953**, absolute difference **0.0085**, allowed tolerance **0.10**. Coverage measures foreground contrast against the dark background; it is the light-on-dark equivalent of stroke darkness. Different letter shapes naturally have different antialiasing. A stronger control renders the same fixture with only the overlay renderer removed: across the complete fixture, **0 changed pixels outside the geometrically predicted strike bands** (sum of RGB channel differences > 8 counts as changed). This includes bold and italic glyphs. Independent actual visual-run assertions pass: plain and regular strike use Regular/Normal, bold strike Bold/Normal, italic strike Regular/Italic.

## 2. Markers — PASS

Look.MarkdownMarker is now **#737F8E** against #171D25. Relative-luminance contrast ratio changes from **4.8862:1** (#7E8B9B) to **4.1612:1**, a **14.84% reduction**. The marker color remains a dedicated Look setting.

## 3. Word-like list indent — PASS

When there is no selection and the caret is at the end of an empty list marker, Tab indents the entire item four spaces. It preserves bullet/task markers and resets numbered items to 1 with their existing . or ) delimiter. Shift+Tab removes one indent level (up to four spaces or one leading tab), and continues the preceding number at the resulting parent indentation when found. Each item replacement is one undo step. Other caret/selection Tab behavior remains in place; code blocks keep their previous Tab behavior.

Seven smoke cases pass with exact text, caret-at-end and one-step undo assertions: dash, star, task and numeric indent; numbered outdent continuing 3 to 4; task outdent; tab-indented star outdent. Existing selection outdent and list Enter cases still pass.

## 4. Standard chrome and app bars — PASS

Enabled full Windows decorations with the normal resizable/minimize/maximize/close chrome. Close uses the existing save-and-hide resident path, like Esc. Actual Close() selftest proves the window hides without quitting. Tray Quit remains; the top bar also offers Quit in the ellipsis menu. Existing save-failure recovery/logging remains verified.

Top bar: New note, Delete note, Previous, Next, Pin, ellipsis/Quit. It wraps at narrow widths. Existing carousel drag strip remains below it. Bottom bar permanently shows n / count, Saved / Saving / save error, and the configured hotkey hint. The fading count indicator/timer was removed. UI colors and fonts derive from Look and the application theme.

Topmost defaults to false. Pin toggles Topmost and persists to the existing runtime settings.json path. Normal window size and position persist atomically; saving while maximized/minimized retains normal restore bounds, and Pin changes still persist in those states. Selftest checks both pin states, including unpin while maximized, persisted JSON, and a size/position restoration round trip. Existing singleton, resident editor identity, second-process show/focus, autosave, reload, carousel wheel/drag/cancellation and caret/scroll checks pass.
