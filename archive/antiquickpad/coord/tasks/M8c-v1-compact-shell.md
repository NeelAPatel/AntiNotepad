## Sub-steps (each ends with the gate and a snapshot)
- **c1 retire Card views:** delete `Views/Card/` and every Card branch in `Views/Common` (`_shellId == "card"` paths, Card palette branch in `ShellPalette`, Card alignment/contract/smoke leftovers). Quiet must render byte-identically to before (`--render-shell quiet light|dark`).
- **c2 V1 window + material:** resident window default 480 x 560 DIP, centred on first run (M8b drops old saved bounds), a sensible minimum (about 360 x 420), `WindowDecorations.BorderOnly`, `ExtendClientAreaToDecorationsHint = true`, title-bar height hint 38. `TransparencyLevelHint = [AcrylicBlur, Mica, None]`; `TransparencyBackgroundFallback` = opaque Quiet canvas. Every layer above the backdrop transparent (window, root, page, editor + template, scroll viewer, carousel surfaces) except ONE tint layer: Quiet canvas at 90 % alpha, as new tokens (e.g. `Look.Material`, `Look.TintAlpha`), not literals in layouts. Editor background renderers that paint regions (code panel, active line) use translucent token colours so the glass still reads through them, as in the V1 mock. Light and dark both.
- **c3 V1 layout:** 14 px mono editor text, 24 DIP side insets, as the mock. **Top bar** (38 DIP): icon-only Pin, New note, More, Close/hide (Segoe Fluent Icons), right-aligned; the full strip stays a drag region (`DragRegion`) whether bars are shown or not. **Bottom pill** (36 DIP): Previous, position text ("3 of 8" from `PositionText`), pager dots (`PagerDots`, `note.select`), Next, save line (`SaveLineText`/`SaveLineFailed`), and "Esc to hide" at the right, as in the mock. Bind everything by command ID through `ShellLayoutContext`; the More menu keeps every entry it has (theme, shell list, delete note, etc.), restyled to the new look (solid surface + shadow is fine). Editor bottom padding so the last lines never sit under the pill (fixes F50-last-lines-clipped visually). Empty-note hint aligned with the first text line (F40 visual part).
- **c4 hover reveal (presentation only):** bars hidden when idle (opacity 0, not hit-testable except the drag strip), shown while the pointer is over the window or keyboard focus is inside a bar or the More menu is open; fade in about 120 ms, fade out about 150 ms after a short (about 400 ms) linger once the pointer leaves. Pure view state in `Views/Quiet` or `Views/Common`, no controller/ViewModel/command. Respect reduced motion if a system flag is already reachable from Views; otherwise note it. Keyboard focus ring visible on bar buttons (F51 visual part).
