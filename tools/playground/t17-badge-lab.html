T17 badge lab: how the dev badge works in worktrees

Hover a chip: it unfurls to the left (the badge is anchored at the pad's right edge) and cross-fades from the resting label to the full one. Light pad uses the tuned text; dark pad keeps the slot color. What the code does today, what it does for each real worktree branch, and the form you asked for. Hover a chip to see its full form, as the app does.

1. How it works today (read from the code)

  1. tools/dev.ps1 builds with -p:AntiNotepadBranch=$(git branch --show-current). In a worktree that is the item branch, for example fix/A11-settings-thread-count. The build time is stamped by the csproj at build, so every relaunch refreshes it.
  2. AppInfo.FormatDevBadge strips only a leading feat/, then reads the ID with ^[A-Za-z][0-9]+[A-Za-z]? (one letter, digits, optional letter). Otherwise it uses the first 12 characters.
  3. Resting text is ⎇ A22 · 3:14 PM. Hover shows ⎇ dev/A22-wrap-indent@2026-11-17 3:14 PM. Main checkout (dev) shows ⎇ dev; a detached HEAD or no stamp shows plain dev.
  4. The chip color is the palette's Number color (the standard purple): text in that color on the same color at 11% (light) or 15% (dark) fill.

Found: item branches named fix/, chore/, docs/ and IDs such as Loop12 are not read as IDs today (see the table). Our worktree branches are prefix/ID-slug (AGENTS.md), so the badge would show junk like chore/T15-ff. The build must fix this for any slot badge to make sense.

2. Every real branch, today vs proposed

Decided: resting form A22-h:mm (12-hour, no AM/PM), hover/full form A22 - name - h:mm AM/PM. The ID is any letters plus digits plus optional letter (A22, T17, Loop12, A43b), after dropping any prefix/. Detached HEAD shows the short build time only; the main checkout keeps dev.

3. Can you read the slot color?

Today's chip writes the text in the badge color on a faint fill of the same color. That works for the purple. The soft slot tones are light, so on a light pad they may be hard to read. Contrast ratio of the text against its chip (WCAG; 4.5 is the usual floor for small text).

Right column: the same chip with the text darkened (light pad) or lightened (dark pad) toward the pad's ink. This is the lab question for the build: keep the color in the fill and border, and tune the text for contrast.
