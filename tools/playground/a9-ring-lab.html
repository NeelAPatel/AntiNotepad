What the code trace found

  • The main window is frameless (border-only decorations, client area extended). Windows 11 itself rounds its corners (about 8 px) and draws the shadow; the app sets no radius of its own for this window (only popups switch rounding off).
  • So the ring would be an overlay border drawn inside the client edge that ignores clicks. Window size, text area and shadow stay as they are.
  • Square corners get clipped by the system rounding, so they look cut off at the corners; rounded (8) follows the window outline exactly.
  • Theme accent is the palette accent, the same color the filled pin icon uses today, so it follows the theme maker.
