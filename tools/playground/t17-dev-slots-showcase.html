T17: several dev copies at once, one color each

A picture of what T17-multi-dev-instances will allow. Nothing here runs the app. Section 4 is a clickable model of the launcher rules.

1. The big picture

Each worktree's dev copy gets a slot. A slot is a color, its own instance id, its own show/hide hotkey and its own data folder. The installed copy sits in its own lane and is never part of the slot system.

3. How a copy shows its color

Two places carry it: the badge in the pad's top bar and the tray (and taskbar) icon. The badge reads ID - name - build time (decided), and its color changes from today's standard purple to the slot color.

Full form when there is room, condensed A22-h:mm (12-hour, no AM/PM; the chip widens and cross-fades to the full form on hover) when the top bar is narrow. Item ID and name come from the branch, as the badge does today. Final tones are lab-first: nothing ships until you approve the lab.

5. Rules in one place

EventWhat happens
LaunchLauncher takes a shared lock so two launches never race. Slot = this worktree's remembered color if free, else the first free color in your order. Slot free means nobody holds its instance id; no stale file can lie. It builds, starts the copy with that id, color and hotkeys, then prints PID, EXE, DATA, HOTKEY, COLOR.
RelaunchSame worktree, same color. Only that slot's copy is asked to quit (exact id, exact exe path, its own data folder), then the new build starts. Other colors keep running.
Seventh launchAll six ids are held by other worktrees. The launcher stops before building and says which worktree holds which color. Nothing is replaced.
Copy closesIts id frees at once. The worktree still remembers its color for next time, unless another worktree needed it.
Worktree removedThe worktree is gone from git worktree list, so its remembered color is dropped at the next launch or tools/dev-list.ps1. A copy still running from it is quit first.
Installed copyDifferent id, different hotkey, different data, no shortcuts touched. The launcher refuses any process whose exe is under Programs\AntiNotepad, as today.
